Number Systems

Natural Numbers

We define basic arithmetic over the natural numbers via the Peano axioms. This definition is zero-inclusive, though some definitions instead split natural numbers (zero-exclusive) from whole numbers (zero-inclusive). 


    The Natural Numbers
        0 is a natural number.
        If n is a natural number, the successor to n S(n) is a natural number.
        There exists no n such that S(n) = 0.
        If S(a) = S(b) then S(a) = S(b).
        A set containing 0 that is closed under the successor operation contains all natural numbers.

    Addition
        a + 0 = a
        a + S(b) = S(a + b)
    Properties
        Associativity, Commutativity
        Identity element (0)
        Cancellation Law
        Monotonicity 
    Subtraction
        a - b = c ≡ a = b + c

    Multiplication
        a × 0 = 0
        a × S(b) = (a × b) + a 
    Properties
        Associativity, Commutativity
        Identity element (1)
        Zero property
        Cancellation Law (for non-zero case)
        Distributivity with Addition 
        Monotonicty
    Division
        a ÷ b = c ≡ a = b × c, b ≠ 0

    Exponentiation
        a^0 = 1
        a^S(b) = (a^b) × a
    Properties
        a^b × a^c = a^(b+c)
        (a^b)^c = a^(b × c)
        (a × b)^c = a^c × b^c
    Logarithm
        log_a(n) = b ≡ a^b = n
        b√n = a ≡ a^b = n
    Properties
        log_a(xy) = log_a(x) + log_a(y)
        log_a(x/y) = log_a(x) - log_a(y)
        log_a(x^y) = y × log_a(x)
        log_a(n) = log_b(n) / log_b(a)
Thus the natural numbers are closed under addition, and multiplication, but not subtraction nor division. More formally, the natural numbers form a commutative monoid under addition, a commutative monoid under multiplication, and thus an ordered semiring.

Then come the integers, rationals, irrationals (which with the previous categories form the reals), the complex numbers and then more exotic categories such as hypercomplex and p-adic numbers.
